# issues
Please submit your issue in this repository
# Rule
If you want to submit an issue, please use `[repository name@type] title` as the issue title. Any issues not using this format will be rejected.

For example `[deltachat-android@Bug]xxxxxxxxxx`
## Types
issue report type: `Feature, Bug, Improve`

If you need help, just use the Question type to ask for help in issues, for example `[deltachat-android@Question]xxxxxxxxxx`
